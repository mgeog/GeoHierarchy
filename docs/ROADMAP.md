# 開発方針とロードマップ

## 設計上の決定事項

### 第3階層の選定基準（案）
第3階層は「中心都市の点」とし、次の規則の和集合とする。

| 規則 | 内容 |
|---|---|
| R1 | 国の首都 |
| R2 | 第2階層ごとの首府（州都・県庁所在地・レジオン首府）。ドイツの都市州は都市自体を首府とする |
| R2′ | 首府を持たない第2階層（英イングランドの地域区分）は、地域内で FUA 人口が最大の都市を代表都市とする |
| R3 | FUA 人口が 100 万以上、または国内の FUA 人口上位 20 都市の中心都市 |

- 国別の学習価値が高い都市（日本の中核市など）を残す「Tier B」の扱いは未決定。
- 基準の限界：閾値は便宜的であること、FUA 人口は 2015 年の推計値で国勢調査と一致しないこと、首府の選定は制度に基づき機能上の中心性と一致しない場合があること、を画面にも明記する。

### 都市圏比較機能
- 階層学習・クイズとは分離した独立機能とする。
- データ：GHSL の GHS-FUA R2019A（基準年 2015）。ライセンスは CC BY 4.0。出典の明記と、改変（投影変換・簡略化）の明示が必要。
  - 取得元：`https://jeodpp.jrc.ec.europa.eu/ftp/jrc-opendata/GHSL/GHS_FUA_UCDB2015_GLOBE_R2019A/V1-0/`
  - 属性：FUA 人口・面積、中心域（UC）人口・面積、通勤圏人口、国コード。
  - 規模：対象国の全件を簡略化（許容誤差 0.01 度）して約 1.2 MB（gzip 約 0.37 MB）。人口上位約 100 件なら約 0.4 MB。
- 留意点：人口は 1 km 格子からの推計、複合都市は 1 件に統合されている（例：ライン・ルール）、各国の公式な都市圏定義とは一致しない。

### 対象国の拡張（中国・インド）
- 公開前に追加する。
- 係争地域を含む境界の描画は Natural Earth の標準に準拠する（それ以上の独自判断はしない）。READMEの免責事項にその旨を記す。
- 台湾・香港・マカオは Natural Earth の区分に従って扱う。
- 広域区分（中国の 7 大区、インドの地域区分）は慣習的区分であり、公式区分との差異を明記する。
- 韓国は第2階層が未完成のため未登録（`southKorea.ts` と `public/data/south-korea.json` は保存）。

## データ検証

```bash
bun run validate
```
