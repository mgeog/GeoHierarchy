# GeoHierarchy

G7各国と中国・インド・韓国の**行政区画と主要都市を、3つの階層で学べる地図アプリ**です。地図の縮尺に応じて、広域区分、州・県、主要都市の順に表示が切り替わり、地図クイズや、世界の都市圏の同縮尺での比較もできます。

## 主な機能

- **3階層の地図**：縮尺連動（自動）か、階層を指定して表示します。国ごとに、見やすいズームを調整しています。
- **地図クイズ**：出題された区画・都市を、地図上でクリックして答えます（10問、ヒント、連続正解、タイマー）。名称を伏せる「暗記マスク」で、形と位置だけで確かめられます。
- **詳細パネル**：人口・面積（出典と基準年つき）、首府、選定基準、都市圏人口を表示します。
- **都市圏比較**：世界の主要388都市圏を、同じ縮尺で重ねる、または並べて、広がり・人口・人口密度を比べます。表で、並べ替え・国別の絞り込み・検索ができます。
- **各国の制度比較**、**検索**（`/` または `Ctrl+K`）、日本語と原語・英語の併記、配色テーマ4種、背景地図6種に対応しています。スマートフォンの画面幅にも対応しています。

## 収録範囲

| 国 | 第1階層（慣習的な広域区分） | 第2階層 | 第3階層（主要都市） |
|---|---|---|---|
| 日本 | 8地方区分 | 47都道府県 | 67（補助枠16を含む） |
| アメリカ | 4国勢調査地域 | 50州と連邦区 | 99（補助枠15を含む） |
| イギリス | 4ブロック | 12地域 | 23（補助枠3を含む） |
| フランス | 4ブロック（本土） | 13レジオン（本土） | 29（補助枠6を含む） |
| ドイツ | 4地域区分 | 16連邦州 | 29（補助枠2を含む） |
| イタリア | 5マクロ地域 | 20州 | 41（補助枠12を含む） |
| カナダ | 5地域 | 10州・3準州 | 25 |
| 中国 | 7大区 | 31省級区画（台湾・香港・マカオを除く） | 111 |
| インド | 6地域（地域評議会） | 28州・8連邦直轄領 | 104 |
| 韓国 | 6広域圏 | 16広域自治団体 | 26 |

- 第1階層には、公式の区分（米国の国勢調査地域など）と、慣習的な区分（日本の地方区分など）が混在します。海外領土は収録していません。
- 韓国は、2026年7月に光州広域市と全羅南道が統合したため、現行の16区画です。

**第3階層の選定基準**：国の首都、第2階層の首府（首府を持たない英イングランドの地域は、域内で都市圏人口が最大の都市）、および、都市圏人口100万以上または国内上位20の都市圏の中心都市です。これらに該当しない都市は、国別の「補助枠」として、控えめに表示し、クイズの対象外としています。詳細は [`docs/ROADMAP.md`](docs/ROADMAP.md) を参照してください。

## データと出典

- **行政境界**：Natural Earth（中国・インド）と、各国の行政界データ。**一部の来歴は、作成時のAIの回答（自己申告）の記録にとどまります。** 係争地域の描画は、Natural Earth の標準に従い、独自の判断は行っていません。
- **人口・面積**：各国の統計機関の公表値（基準年は国により異なります）。Wikipedia の統計表から転記しており、一次資料での再照合は未実施です。
- **都市圏**：[GHSL: GHS-FUA R2019A](https://human-settlement.emergency.copernicus.eu/ghs_fua.php)（欧州委員会 共同研究センター、CC BY 4.0、2015年）。投影変換・単純化などの改変を行っています。人口は格子データからの推計値です。
- **背景地図**：OpenStreetMap ほか（アプリ内に帰属表示）。**OSM France と Esri のタイルは、利用条件が未確認です。**
- **フォント**：Noto Sans JP（SIL OFL 1.1、自前配信）。

出典・ライセンス・確認状況の詳細は [`docs/DATA_SOURCES.md`](docs/DATA_SOURCES.md)、作成時のAIの回答の原文は [`docs/PROVENANCE_GEMINI.md`](docs/PROVENANCE_GEMINI.md) にあります。教育用の地図であり、表示する境界線・名称は、いかなる国家・地域の政治的立場も表明しません。法的な手続きや、高精度を要する用途には使えません。

## 開発

React 19、TypeScript、Vite、Tailwind CSS 4、Leaflet、d3-geo で構成し、Bun で管理しています。

```bash
bun install
bun run dev        # 開発サーバー（ポート 3000）
bun run lint       # 型検査
bun run validate   # データの整合性（親子関係、首府、FUA の代表都市、境界との対応など）
bun run test       # 単体テスト（vitest）
bun run build      # 本番ビルド（dist）
```

データは、`src/data/countries`（国ごとの定義）、`src/data/selection`（第3階層の選定）、`src/data/statistics.json`（人口・面積と出典）、`public/data`（境界、都市圏の境界）にあります。
